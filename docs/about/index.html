글을 쓰는 기준

  • 직접 다녀온 후기와 사전 조사 글을 구분합니다. 사전 조사 글에는 제목 옆에 "사전 조사" 표시가 붙습니다.
  • 출처를 적습니다. 카카오맵, 여기어때, 관광 안내 사이트, 기사 등 어디서 본 정보인지 글 끝에 남깁니다.
  • 모르는 것은 모른다고 씁니다. 요금이나 운영시간을 찾지 못하면 추정하지 않고 "확인하지 못함"이라고 적습니다.
  • 정보 확인일을 표시합니다. 가격과 운영시간은 바뀌므로 글 상단에 확인한 날짜를 적습니다.
